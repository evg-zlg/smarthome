# Реестр клиентов и устройств

Каждый каталог первого уровня соответствует отдельному клиенту. Доступы одного
клиента не используются для устройств другого клиента.

Структура:

```text
clients/<client-id>/
  ssh_config
  credentials/ssh/id_ed25519
  credentials/ssh/id_ed25519.pub
  credentials/wifi/<connection>.nmconnection
  credentials/<system>/<credential-file>.yaml
  devices/<device-id>.yaml
```

Подключение выполняется переносимым wrapper из корня любого клона:

```bash
scripts/device-ssh <client-id> <device-id>
```

Все клиентские доступы — SSH-ключи, Wi-Fi-пароли, логины, пароли, API-токены и
сертификаты — намеренно хранятся в соответствующем каталоге `credentials/` для
бесшовной работы разных машин и сессий. Любой пользователь с доступом к
репозиторию получает доступ к устройствам и сетям. Репозиторий нельзя делать
публичным.
