# Design QA: визуальная доработка главной evoHome

Дата: 2026-09-20. Состояние: локальная production-сборка, без авторизации.

## Артефакты и нормализация

- Source visual truth: `../plans/website-homepage-evohome.png`, 941 × 1672 px.
- Implementation desktop: `design-implementation-homepage.png`, 1440 × 6000 px, CSS viewport 1440 × 6000, device scale 1.
- Implementation mobile: `design-implementation-mobile.png`, 390 × 844 px, CSS viewport 390 × 844, device scale 1.
- Совмещённое сравнение: `design-qa-comparison.png`, source и implementation в одном кадре.
- Сравнение выполнено по одинаковому состоянию главной страницы. Из-за разной исходной длины макета оценивались композиция, масштаб и ритм секций, а не точное совпадение координат.

## Сравнение и обязательные поверхности

- Типографика: сохранена контрастная пара крупной антиквы и нейтрального гротеска; масштаб и переносы заголовков соответствуют editorial-направлению. Осталась допустимая P3-разница из-за системной Georgia.
- Ритм и компоновка: вместо одного разреженного ряда теперь есть связная последовательность hero → тип объекта → выгоды → решения → этапы → проект → контакт. На 390 px сетки складываются в одну колонку без горизонтального переполнения.
- Цвета: тёплый ivory, графит, тонкие серо-бежевые разделители и белые CTA соответствуют исходному visual direction; градиенты и тяжёлые тени не добавлялись.
- Изображения: новые интерьерные кадры резкие, согласованы по температуре и кадрированию; план квартиры сохранён как схематический инженерный акцент.
- Тексты: пользовательская польза описана конкретно — комфорт, безопасность, локальная работа, этапы и следующий шаг.
- Focused regions: отдельно проверены hero с объектной навигацией, три карточки выгод, карточки решений и мобильный первый экран. Эти области содержат основные типографические, сеточные и image-crop риски.

## История итераций

1. [P1] В прежней версии нижняя часть главной состояла из трёх пустых карточек высотой около 300 px и не воспроизводила плотность исходного макета. Evidence: пользовательский скриншот и предыдущий `design-implementation-homepage.png`.
2. Исправление: пустой ряд удалён; добавлены визуальные карточки типов объектов, три benefit-блока, решения с изображениями, четыре этапа, широкий проектный баннер и компактный CTA.
3. Post-fix evidence: `design-qa-comparison.png`, desktop-скриншот и browser-проверка всех секций. Ранее найденный P1 устранён; новых P0/P1/P2 нет.

## Проверки

- `npm run build`: успешно, 5 статических маршрутов.
- Встроенный браузер: desktop 1440 × 1000 и mobile 390 × 844.
- Основные ссылки и семантические элементы присутствуют в accessibility tree.
- Консоль приложения: ошибок не обнаружено.

## Findings

- Действующих P0/P1/P2 замечаний нет.
- [P3] После получения брендового display-шрифта стоит заменить Georgia, чтобы точнее повторить пластику референса.
- [P3] Исходный макет содержит иной набор интерьерных сюжетов; текущие изображения выдерживают арт-дирекцию, но не являются покадровыми копиями.

final result: passed
