# Локальный сайт evoHome

Многостраничный Astro-сайт evoHome по утверждённому визуальному направлению.

## Страницы

- `/` — главная;
- `/solutions/` — каталог типовых решений;
- `/solutions/lux-2-room/` — решение «Люкс для 2-комнатной квартиры» с интерактивной схемой;
- `/about/` — подход к проектированию;
- `/contacts/` — форма обращения и контакты.

Шапка и подвал общие для всех страниц. Основная навигация и CTA ведут на реальные маршруты, а не на секции одной длинной страницы.

## Запуск

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:4321`.

## Сборка

```bash
npm run build
```

Локальные фото находятся в `public/media/images`, инструкции по видео — в `public/media/video/README.md`. До добавления роликов сайт работает без внешних медиазависимостей.
