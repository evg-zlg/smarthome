# Локальный сайт evoHome

Astro-прототип страницы решения «Люкс для 2-комнатной квартиры» по утверждённому третьему визуальному направлению.

## Запуск

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:4321`.

## Сборка

```bash
npm run build
```

Локальные фото находятся в `public/media/images`, инструкции по видео — в `public/media/video/README.md`.
