# Локальные видео evoHome

Положите сюда скачанные из Telegram ролики с такими именами:

- `office-ecosystem.mp4` — экосистема умного дома;
- `ideal-climate.mp4` — идеальный климат;
- `automatic-gates.mp4` — автоматические ворота.

После добавления файлов карточки в `src/pages/index.astro` можно заменить на обычные элементы `<video controls>` с путями `/media/video/<имя-файла>`.

Поздравительные ролики для сайта не используются.
