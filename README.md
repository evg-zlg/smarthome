# smarthome

Репозиторий для проектирования, настройки и документирования умных домов на базе разных технологий.

## Принципы

- безопасное поведение при отказах;
- локальное управление там, где это возможно;
- сохранение ручного управления критичными функциями;
- конфигурация как код и воспроизводимые изменения;
- отсутствие секретов и персональных данных в Git;
- документирование фактического состояния системы.

## Структура

- [`AGENTS.md`](AGENTS.md) — обязательные правила работы с проектом;
- [`docs/architecture/`](docs/architecture/) — архитектура и границы системы;
- [`docs/inventory/`](docs/inventory/) — обезличенный реестр оборудования;
- [`docs/rfc/`](docs/rfc/) — активные RFC;
- [`docs/runbooks/`](docs/runbooks/) — инструкции по эксплуатации и восстановлению;
- [`docs/specs/`](docs/specs/) — актуальные спецификации реализованных решений.

## Как начать изменение

1. Обновить сведения об `origin/main` и создать отдельный чистый worktree для сессии.
2. Изучить архитектуру и связанные спецификации внутри этого worktree.
3. Для значимого изменения скопировать [`docs/rfc/template.md`](docs/rfc/template.md) в `docs/rfc/<slug>.md`.
4. Согласовать решение и критерии приёмки.
5. Реализовать и проверить изменение от безопасного контура к реальному.
6. Обновить актуальные спецификации и перенести RFC в `docs/rfc/archive/`.

Общая директория репозитория не используется для разработки. Каждая сессия работает в собственном worktree от актуального `origin/main`. Worktree удаляется только по явной команде «чисти» или «закрывай» и только после проверки сохранности данных. Полный протокол описан в [`AGENTS.md`](AGENTS.md).

Процесс вдохновлён подходом [DD-SDD](https://github.com/anatolii-iumashev/dd-sdd) и адаптирован для эксплуатации умного дома.

## Raspberry Pi 3B

- хост: `rasppi3b` (`192.168.0.138`);
- пользователь автоматизации: `smarthome`;
- подключение из корня репозитория: `ssh -F ssh_config rasppi3b`;
- SSH-конфигурация: [`ssh_config`](ssh_config);
- публичный ключ: [`docs/keys/rasppi3b_ed25519.pub`](docs/keys/rasppi3b_ed25519.pub).

Приватный ключ `.ssh/rasppi3b_ed25519` хранится только локально и исключён из Git.
Пользователь состоит в группе `sudo`, но административные команды требуют отдельной настройки пароля или ограниченного правила `sudoers`.
