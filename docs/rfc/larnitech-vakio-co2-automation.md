# Дневная автоматика VAKIO по CO₂

## Решение

Постоянный контроль CO₂ выполняется отдельным Blockly-сценарием Larnitech
`315:245` (`VAKIO · CO₂ автоматика`). Сценарий `Доброе утро` включает его, а
`Спокойной ночи` отключает перед переводом VAKIO в ночной режим.

Пороговая логика:

- `CO₂ >= 1000 ppm` — летняя рекуперация, скорость 6;
- `CO₂ <= 800 ppm` — питание VAKIO выключено;
- диапазон 800–1000 ppm — состояние не меняется;
- повтор одной ветви ограничен интервалом 60 секунд.

Команды передаются через виртуальные сущности Larnitech `407:220`–`407:234` и
существующий локальный gateway на Raspberry Pi. Выбор режима или скорости на
gateway сначала обеспечивает включённое питание VAKIO и подтверждает ответ
устройства через MQTT.

## Безопасное состояние и откат

После перезапуска или ручного выключения `315:245` новые команды по CO₂ не
отправляются. Ночной сценарий всегда отключает дневную автоматику до выбора
ночного режима.

Откат:

1. выключить `315:245`;
2. восстановить XML сценариев из
   `/private/tmp/larnitech-scenarios-before-vakio-link.json`;
3. при необходимости удалить созданный сценарий по резервному перечню
   `/private/tmp/larnitech-scripts-before-vakio-co2.json`;
4. вручную выбрать безопасный режим VAKIO и проверить подтверждённое состояние.

## Проверка

- `Scripts.get` подтвердил блоки и адреса всех трёх сценариев;
- скомпилированный `logic0315.txt` содержит пороги 1000/800, режим
  рекуперации, скорость 6, выключение питания и включение `315:245` утром;
- скомпилированный `logic0407.txt` содержит выключение `315:245`, ночной режим
  и отложенную на 2 секунды скорость 1;
- API2 подтвердил состояние `315:245 = off` после настройки;
- физический запуск и проверка реакции VAKIO не выполнялись, поскольку сценарии
  также управляют светом и шторами.

## Критерии приёмки

- [x] Порог включения — 1000 ppm, выключения — 800 ppm.
- [x] Дневная автоматика включается утром и отключается ночью.
- [x] Ночью выбираются ночной режим и скорость 1 в заданном порядке.
- [x] Сценарии сохранены и повторно прочитаны из Larnitech.
- [ ] Фактическая реакция VAKIO проверена при наблюдении на объекте.
