# Runbooks

Здесь хранятся пошаговые инструкции для эксплуатации и аварийного восстановления.

Для каждого значимого контура желательно иметь инструкции:

- как проверить состояние системы;
- как безопасно перезапустить компоненты;
- как перейти на ручное управление;
- как восстановиться из резервной копии;
- как заменить шлюз или контроллер;
- как действовать при потере сети, питания или облачного сервиса;
- как проверить результат восстановления.

Инструкция должна быть понятна человеку, который не участвовал в первоначальной настройке.
