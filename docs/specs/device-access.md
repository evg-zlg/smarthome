# Доступ к устройствам

## Модель хранения

Доступ организован по клиентам в `clients/<client-id>/`. У каждого клиента есть
собственный SSH-ключ, SSH-конфигурация и реестр устройств. Ключ одного клиента
не должен устанавливаться на устройства другого клиента.

Приватные SSH-ключи намеренно хранятся в приватном Git-репозитории. Это решение
выбрано ради бесшовной работы разных компьютеров и автоматических сессий. Любой,
кто получает копию репозитория, получает доступ ко всем перечисленным в нём
устройствам.

## Подключение

```bash
scripts/device-ssh <client-id> <device-id> [command]
```

Wrapper вычисляет путь текущего клона, выбирает конфигурацию и ключ клиента и
исправляет локальные права приватного ключа на `0600`.

## Текущее устройство

```bash
scripts/device-ssh home rasppi3b
scripts/device-ssh home rasppi3b 'sudo -n id'
```

На `rasppi3b` пользователь `smarthome` входит по ключу и имеет полный
passwordless sudo через `/etc/sudoers.d/90-smarthome`.

## Добавление клиента

1. Создать `clients/<client-id>/credentials/ssh/`.
2. Сгенерировать отдельный Ed25519-ключ без passphrase.
3. Добавить хосты в `clients/<client-id>/ssh_config`.
4. Добавить карточки устройств в `clients/<client-id>/devices/`.
5. Установить публичный ключ и sudo-правило командой
   `scripts/configure-device-access.sh` из административной сессии устройства.
6. Проверить вход и `sudo -n` через `scripts/device-ssh`.
