# Актуальные спецификации

`docs/specs/` описывает фактическое текущее состояние системы, а не планы.

Актуальные документы объекта:

- [Кондиционер и шлюз ONOKOM в офисе](office-air-conditioner.md)

После завершения изменения здесь фиксируются:

- что работает и где проходит граница решения;
- используемые технологии, версии и зависимости;
- фактическое поведение в штатных и отказных сценариях;
- принятые решения и отклонения от RFC;
- известные ограничения;
- ссылки на runbook, инвентарь и архивный RFC.

Рекомендуемый frontmatter нового документа:

```yaml
---
title: "<название системы или функции>"
status: done
completed: YYYY-MM-DD
rfc: ../rfc/archive/<slug>.md
---
```
