# Инвентарь

Здесь хранится обезличенное описание оборудования и интеграций. Не указывайте точный адрес дома, реальные IP-адреса внешнего доступа, ключи, серийные номера, MAC-адреса и другие чувствительные идентификаторы.

Рекомендуемые поля для устройства:

| Поле | Описание |
| --- | --- |
| ID | Стабильный внутренний идентификатор |
| Зона | Обобщённое помещение или функциональная зона |
| Тип | Датчик, реле, выключатель, шлюз и т. п. |
| Производитель и модель | Точная модель оборудования |
| Протокол | Matter, Thread, Zigbee, Z-Wave, Wi-Fi, MQTT и т. п. |
| Контроллер или шлюз | Через что устройство подключено |
| Питание | Сеть, батарея, PoE, UPS |
| Критичность | Низкая, средняя, высокая |
| Безопасное состояние | Поведение при отказе связи или питания |
| Версия | Проверенная версия прошивки |
| Ограничения | Известные проблемы совместимости |
